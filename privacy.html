1. GHOSTTRACE is self-hosted software

GHOSTTRACE is open-source, self-hosted software. The operator runs their own instance — on their own machine or homelab. There is no GHOSTTRACE company server. The people who write the software do not host your data, receive your data, or operate any central service.

Because each instance is run by its operator, the operator is responsible for that deployment: what gets connected, where the instance runs, and how it complies with applicable law. This policy describes what the software itself can collect and how it handles what it collects.

2. This website

This site (the landing page, this policy, and the terms page) is plain static HTML served from a repository. It sets no cookies, loads no third-party scripts or fonts, runs no analytics and no tracking pixels, and asks for no personal information.

3. Data collected per integration

Nothing is collected until an operator enables an integration, and every integration is optional. What each one can collect is listed below — exactly, and nothing beyond it.

3.1 Google account (OAuth)

Connecting a Google account uses OAuth with the openid, email and profile scopes, which return your name, email address and profile information. With optional, separately consented read-only scopes:

  • Gmail (gmail.readonly) — only security-alert emails sent by no-reply@accounts.google.com are read, and only the subject line and date are stored. Message bodies are never read into storage.
  • Calendar (calendar.readonly) — the title, time and location of recent events.
  • Drive (drive.readonly) — file names and modified times only. File contents are never read.

3.2 GitHub

GHOSTTRACE reads your public activity events: pushes, pull requests, issues and stars. If you optionally add a personal access token (PAT), it grants access to your own private events only — never anyone else's.

3.3 ActivityWatch & Wazuh

These integrations collect nothing new. They read data already collected by those local tools on your machine, and only via the APIs ActivityWatch and Wazuh themselves expose.

3.4 Android / iOS companion app

The companion app reports device telemetry: battery level, network type, OS/app version, device location — only when you grant the explicit OS permission for it — and app-usage events your device reports.

3.5 Google Takeout import

Whatever you choose to upload, GHOSTTRACE imports — for example location history or activity entries from your own Takeout archive. The software does not fetch Takeout data on its own.

4. Storage & protection

Inside your instance, collected data is protected as follows:

ConcernHow GHOSTTRACE handles it
PasswordsHashed with bcrypt — never stored in plain text.
OAuth tokens & secretsEncrypted at rest with Fernet.
SessionsAccess and refresh JWTs backed by server-side session records, with per-session revocation.
AccountabilityAn audit log of security events.
RetentionConfigurable, with a default of 90 days — collected events age out unless the operator raises the window.

5. What never happens

GHOSTTRACE does not sell data. It includes no third-party analytics and no tracking pixels — not in the software, and not on this website.

6. Deletion & your controls

From Settings, you can delete your account. Deleting it:

  • revokes your Google tokens,
  • and permanently cascades deletion of all collected events tied to your account.

You can also inspect every active session and API key, and revoke any one of them individually without deleting the whole account. If you use an instance operated by someone else, the operator controls the deployment — deletion of your data on their instance runs through their copy of this software and their retention settings.
